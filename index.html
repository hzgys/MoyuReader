它能做什么

透明置顶无边框全透明窗口（黑字），永远浮在工作窗口上面；想要底色随时可调，文字自动换色
Option + H 老板键全局热键一键隐藏 / 唤回，不需要辅助功能权限
章节跳转自动解析目录，Cmd + T 打开、Cmd + ←/→ 上下章，正则可自定义
自动翻页空格 开始，逐行滚动或整页翻页，鼠标悬停自动暂停
菜单栏常驻菜单栏书本图标随时唤回窗口、打开 TXT、退出
进度记忆按文件记住阅读位置，下次打开直接回到原处
编码识别UTF-8 / UTF-16 / GB18030 自动识别，中文 TXT 拖进来就能读
双击关闭双击窗口任意位置立即收起，Option + H 或菜单栏图标随时唤回
随手好用全窗口拖动移动、边缘拉伸改大小、点击唤出进度条和窗口按钮

快捷键

Option + H老板键：全局隐藏 / 唤回窗口
空格开始 / 停止自动阅读
双击窗口收起窗口（Option + H 或菜单栏图标唤回）
Cmd + O打开 TXT 文件
Cmd + T章节目录
Cmd + ← / →上一章 / 下一章
Cmd + + / −字体放大 / 缩小
Cmd + Q退出

首次打开

App 未购买苹果开发者证书（$99/年），首次打开会被 Gatekeeper 拦一次。在终端执行：
xattr -dr com.apple.quarantine /Applications/MoyuReader.app
或者：右键点击 App →「打开」→ 再点「打开」。之后双击即用，不会再有提示。
打开 TXT：拖进窗口、Cmd + O、菜单栏图标 → 打开，或在 Finder「打开方式」里选 MoyuReader。
